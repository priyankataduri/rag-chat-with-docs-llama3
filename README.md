# Chat with Docs: RAG using Llama 3

A Retrieval-Augmented Generation (RAG) app that lets you upload a PDF and ask questions about it. Answers are generated by a locally running Llama 3 model and grounded in the content of your document.

## How it works

1. **Load:** The PDF is read with LlamaIndex's `SimpleDirectoryReader`.
2. **Embed:** Text chunks are converted into vectors with the `BAAI/bge-large-en-v1.5` embedding model from Hugging Face.
3. **Index:** Vectors are stored in a vector index (Qdrant in `main.py`, in-memory in `app.py`).
4. **Retrieve:** For each question, the most relevant chunks are retrieved.
5. **Generate:** A custom prompt template passes the retrieved context and question to Llama 3 (8B Instruct, via Ollama), which streams back an answer. If the answer is not in the document, the model is instructed to say "I don't know!"

## Features

- PDF upload with in-app preview
- Streaming chat responses
- Document summarization and fact-checking against the uploaded file
- Per-session caching so a document is only indexed once
- "Clear" button to reset the conversation

## Tech stack

Python, LlamaIndex, Ollama (Llama 3 8B Instruct), Hugging Face embeddings (BGE), Qdrant, Streamlit

## Files

| File | Purpose |
| --- | --- |
| `app.py` | Streamlit chat app: upload a PDF and chat with it |
| `main.py` | Script version: indexes a folder of PDFs (Qdrant) and runs a sample query |
| `requirements.txt` | Python dependencies |

## Setup

1. Install [Ollama](https://ollama.com) and pull the model:
   ```bash
   ollama pull llama3:8b-instruct-q4_1
   ```
2. Install the Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. (Optional, for `main.py`) Start Qdrant locally:
   ```bash
   docker run -p 6333:6333 qdrant/qdrant
   ```

## Run

Chat app:
```bash
streamlit run app.py
```

Script version (update `input_dir_path` in `main.py` to your PDF folder first):
```bash
python main.py
```
